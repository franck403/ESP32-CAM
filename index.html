ESP32 Camera

Install the camera script over USB, then watch it over USB or WiFi.

This browser has no Web Serial. Use Chrome or Edge on a PC.

1. Install

Fetches main.py from this site and writes it to the board over USB at 115200 baud. Close Thonny or any serial monitor first. When it is done, the installer asks the board for its WiFi IP and saves it for the WiFi viewer.
